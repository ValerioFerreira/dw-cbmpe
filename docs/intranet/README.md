# Documentação da intranet do CBMPE (exportada do BookStack)

Esta pasta guarda o que for exportado do wiki interno
(`docs.captain.cbmpe.intranet`), para que o conhecimento sobrevivа a
sessões e não dependa de acesso à rede interna.

**Como exportar**: no BookStack, cada página tem `Exportar → Markdown`; o
livro inteiro também pode ser exportado de uma vez pelo menu do livro.

Páginas que interessam ao deploy deste projeto no CapRover:

- Operação e recuperação de desastre — o procedimento de deploy pelo CapRover CLI
- Guia de integração — como plugar um sistema novo no SGU (autenticação)
- Configuração e infraestrutura — onde ficam as envs (App Configs do CapRover)
- Gotchas e achados críticos — as armadilhas conhecidas (Port Mapping 9090)
- _Template de Sistema — o modelo a preencher para cada sistema novo

**Regra herdada do wiki, e adotada aqui**: nenhum valor de segredo entra
nestes arquivos. Só o mapa de onde eles estão.
